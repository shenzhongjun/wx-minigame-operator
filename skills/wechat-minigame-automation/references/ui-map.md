# ui-map — 界面按钮认知地图（语义/判据/红线；坐标一律见 coords.md，本文件零坐标）

> **定位**：界面按钮认知普查（2026-10-28 立项）的语义侧产出。每个按钮记：语义（按了去哪/干什么）、判据（怎么确认状态）、红线标记。**坐标唯一入口 = `coords.md` 通用坐标表，本文件禁止出现坐标。**
> **普查方式**：用户口述讲解 + 归一化网格截图量取 + 实机点击验证（安全按钮）/留档不点（涉钱/消耗类）。
> **判据现状（2026-10-30）**：本轮只量点击坐标；**OCR 判据一律未量**（用户令：记开发待办，与用户一起量）；主城 town OCR 实机 MISS 异常待重标（见开发待办）。
