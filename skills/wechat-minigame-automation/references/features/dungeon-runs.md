# 功能模块 · 副本刷取流程（冥渊 / 堕落圣殿 / 邦庄航路）

> **目的**：用户说「刷深渊/冥渊」「刷圣殿」「刷航路」及每日标准循环的执行环节。
> **触发**：任务指令含对应副本关键词；循环定义见 `game-mechanics.md`。
> **脚本**：wxclick / wxgrind / wxprobe（用法见 SKILL.md 清单；wxfarm 已删除——未迁移设计坐标且被 wxgrind 覆盖，2026-10-26 用户裁决）。
> **坐标**：引自 `coords.md` 通用坐标表（表为标定权威源，此处为执行引用值；全部是设计坐标 1138×708，脚本自动换算）。
> **机制数值**（体力/邀请函/免费首把/刷新时间）：见 `game-mechanics.md`，本文件不重复。

## 通用流程骨架

进图 → 等 3.9~4.5s → 探针 AUTO 状态（AUTO_OFF 才点 (224,181)）→ wxgrind「再来一次」循环 → 结算。

## 冥渊模式（用户说「刷深渊/冥渊」）

```
选角 → 开始游戏(1018,634) → 地图(82,109) → 冥渊(276,342)
→ 确认「开启冥渊」变「冥渊模式」(1057,588) → 选目标图 → 开始战斗(928,595)
→ 等 4.5s → 探针 AUTO 状态 → wxgrind 探针「再来一次」循环
```

选图坐标（冥渊模式布局）：入口-3 (285,269)｜炎之魔域-3 卡片中心 (585,264)｜冰之魔域-3 (681,462)｜暗之魔域-3 (1000,454)。

流程特有注意事项：

- 时长基准：多房间约 45~55s/场（血量每场开始回满，机制见 game-mechanics.md）；拿不准宁可多等 3~5s。
- 「选择奖励」面板只点「免费」图块，**绝不点「支付金币 4500」**。
- 结算有简化版（两行/三行按钮）与全屏「战斗胜利」两种，后者点空白收起。
- **冥渊节点点击后页面过渡可能 >2.5s，跟进点击会点到已开页面的卡片**（两次入口-1 弹窗教训，事件12）——冥渊导航后必须截图核对再动作。
- 体力不足 7 仍可进最后一把（机制例外）；邀请函 0 即终止（判定与弹窗见 game-mechanics.md）。

## 堕落圣殿（远古副本）

```
开始游戏(1018,634) → 冒险(936,664) → 副本(843,563) → 远古副本(70,231)
→ 堕落圣殿(419,348) → 开始战斗(948,592) → 等3.9s → 探针 AUTO 状态
→ wxgrind「再来一次」循环
```

- 单房间 35~60s（**角色1/2 伤害高实际 ~30s/场**，2026-10-24 用户指示等待基准降为 30s；角色3/4 伤害待实测后再定）。
- 每天第一把免费（仅远古副本，机制见 game-mechanics.md）；体力不足点开始战斗只弹「体力 数量:N」。
- **结算页固定坐标（两行布局，2026-10-24 实测 2/2 全中）：再来一次 (936,269)、返回城镇 (936,340)**；按钮 RGB 实测 R≈105-118 G≈43-62 B≈35-53（旧 IsRed 判定式吻合；wxfarm 当晚失灵原因未定，悬案已随 wxfarm 删除作废，见 todo-scripts 废弃标记）。固化循环用 `wxgrind.ps1`（固定坐标+探针验证）。
- 点卡片直接进**堕落圣殿-1**（圣殿子层）；弹窗内「每日奖励次数 N/1」可作为当日已打把数证据。
- **CopyFromScreen 报「句柄无效」= 屏幕锁定/会话切走特征**（2026-10-24 实测），解锁后自愈；此时点击也不可靠，先停手。
- 体力不足时结算后直接退回副本列表（wxgrind 结算等待超时 = 正常结束）。

## 邦庄航路

```
冒险(936,664) → 副本(843,563) → 邦庄航路(70,506)
→ 小队突击(986,637) → 弹窗「开始游戏」(572,586) → 等 4.5s
→ 探针 AUTO 状态 → wxgrind「再来一次」循环
```

- 一场消耗 10 体力（见 game-mechanics.md），单房间 40~55s；小队突击弹窗空位（+号）可不加队友。
- 探针注意：航路场景绿色毒雾特效会污染体力弹窗判定（STAMINA_POP 已在探针中降低优先级）。
- 两行结算「再来一次」实测 **(936,244)**（比圣殿高 25px，面板浮动）；2026-10-24 wxgrind 10 轮全 1 次点击入场零异常。

## 停止条件

- 圣殿/航路：体力不足弹窗；冥渊：邀请函 0（判定见 game-mechanics.md）；
- 用户指令、熔断触发（见专家包 agent 定义）。
