> **目的**：用户说「刷深渊/冥渊」「刷圣殿」「刷航路」及每日标准循环的执行环节。
> **触发**：任务指令含对应副本关键词；循环定义见 `tasks.md`「每日标准循环」。
> **脚本**：wxclick / wxgrind / wxprobe（用法见 SKILL.md 清单；wxfarm 已删除——未迁移设计坐标且被 wxgrind 覆盖，2026-10-26 用户裁决）。
> **坐标**：**本文件零坐标**（唯一坐标入口=`coords.md` 通用坐标表；此处只写流程与语义，防双源漂移）。
> **机制数值**（体力/邀请函/免费首把/刷新时间）：见 `game-mechanics.md`，本文件不重复。

> **坐标铁律：本文件零坐标——所有按钮/入口坐标一律查 `coords.md` 通用坐标表（唯一坐标入口），此处只写流程步骤与语义。**

## 通用流程骨架

进图 → **立即调 wxautoensure**（OCR 轮询，转场黑屏 UNKNOWN 自动继续，无需等加载；实测 2.0s 开启）→ wxgrind「再来一次」循环 → 结算。

## 冥渊模式（用户说「刷深渊/冥渊」）

```
选角 → 开始游戏 → 地图 → 冥渊（单次点击）
→ 确认「开启冥渊」变「冥渊模式」 → 选目标图（各魔域-3 坐标见 coords.md「冥渊模式选图」行）→ 开始战斗
→ 立即 wxautoensure → wxgrind 探针「再来一次」循环
```

流程特有注意事项：

- 时长基准：多房间约 45~55s/场（血量每场开始回满，机制见 game-mechanics.md）；拿不准宁可多等 3~5s。
- 「选择奖励」面板只点「免费」图块，**绝不点「支付金币 4500」**。
- 结算有简化版（两栏/三栏按钮）与全屏「战斗胜利」两种，后者点空白收起。
- **冥渊节点点击后页面过渡可能 >2.5s，跟进点击会点到已开页面的卡片**（两次入口-1 弹窗教训，事件12）——冥渊导航后必须截图核对再动作。
- 体力不足 7 仍可进最后一把（机制例外）；邀请函 0 即终止（判定与弹窗见 game-mechanics.md）。

## 堕落圣殿（远古副本）

```
开始游戏 → 冒险 → 副本 → 远古副本 → 堕落圣殿 → 开始战斗 → 立即 wxautoensure
→ wxgrind「再来一次」循环
```

（各步坐标见 coords.md：开始游戏/冒险/副本/远古副本/堕落圣殿/开始战斗各行。）

- 单房间 35~60s（**角色1/2 伤害高实际 ~30s/场**，2026-10-24 用户指示等待基准降为 30s；角色3/4 伤害待实测后再定）。
- 每天第一把免费（仅远古副本，机制见 game-mechanics.md）；体力不足点开始战斗只弹「体力 数量:N」。
- 结算按钮定位=通用法（coords.md「结算页」行，两栏）；**旧固定坐标 (936,269)/(936,340) 已作废删除**（面板浮动，禁写死）。固化循环用 `wxgrind.ps1`（探针验证+自动扫描）。
- 点卡片直接进**堕落圣殿-1**（圣殿子层）；弹窗内「每日奖励次数 N/1」可作为当日已打把数证据。
- **CopyFromScreen 报「句柄无效」= 屏幕锁定/会话切走特征**（环境坑唯一归属=`run-environment-pitfalls.md` §4）：停手，解锁后自愈；此时点击也不可靠。
- 体力不足时结算后直接退回副本列表（wxgrind 结算等待超时 = 正常结束）。

## 邦庄航路

```
冒险 → 副本 → 邦庄航路 → 小队突击 → 弹窗「开始游戏」→ 立即 wxautoensure
→ wxgrind「再来一次」循环
```

（坐标见 coords.md：冒险/副本/邦庄航路/小队突击/开始游戏各行。）

- 一场消耗 10 体力（见 game-mechanics.md），单房间 40~55s；小队突击弹窗空位（+号）可不加队友。
- 探针注意：航路场景绿色毒雾特效会污染体力弹窗判定（STAMINA_POP 已在探针中降低优先级）。
- 「再来一次」两栏/三栏均在第一栏、位置相同不变（旧「面板 Y 浮动」系两栏/三栏未分清，作废）；待实机验证后坐标固化写死（开发待办），验证前以 wxgrind 扫描兜底（旧实测 (936,244) 已随通用法作废）；2026-10-24 wxgrind 10 轮全 1 次点击入场零异常。

## 停止条件

- 圣殿/航路：体力不足弹窗；冥渊：邀请函 0（判定见 game-mechanics.md）；
- 用户指令、熔断触发（见专家包 agent 定义）。
