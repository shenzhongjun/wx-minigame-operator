# 功能模块 · 每日领体力（商城免费礼包，全体角色）

> **目的**：领商城每日免费体力与不死鸟羽毛。
> **触发**：每日标准循环第一步；每日 12:00 体力刷新后。
> **脚本**：wxclick（用法见 SKILL.md 清单）。
> **坐标**：**本文件零坐标**（唯一坐标入口=`coords.md` 通用坐标表）。
> **机制前提**（刷新时间/领取上限/福利按钮规则）：见 `game-mechanics.md`，本文件不重复。

> **坐标铁律：本文件零坐标——所有按钮坐标一律查 `coords.md` 通用坐标表（开始游戏/商城/礼包分类/每日体力·免费/不死鸟羽毛·免费/商城弹窗空白/返回键各行动作点）。**

顺序固定：先「每日体力礼包（免费）」(+10)，再「不死鸟羽毛（免费）」(+1)。

```
连招A：选角卡 → 开始游戏 → 等5s → 商城 → 礼包 → 截图确认
连招B：体力·免费 → 空白关弹窗 → 羽毛·免费 → 空白关弹窗 → 返回 → 选角 → 截图确认
```

流程特有注意事项：

- 进主城加载不稳定是最大坑：分两段、每段末截图确认。落「神秘·每日商店」页补点「礼包分类」；进背包点返回键。
- 验证信号：选角页体力变 110/100；羽毛变「已售罄」；礼包「角色日限」10/10→9/10（剩余转付费 60 点券，勿买）。
- ⚠️ **礼包页布局会随领取状态变化（已领过的角色再进会看到付费卡），wxclaim 一键链已禁用盲跑**——固化按自主探索模式执行（2026-10-28 带教退役）：截图确认布局 → 每次点击后核对，见付费卡/涉钱弹窗即停上报（事件16）。
- 角色1（大号）专属「福利」按钮领取规则见 game-mechanics.md。
