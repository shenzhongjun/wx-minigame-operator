# 坐标与流程档案 · 公司电脑（DPI-unaware 窗口相对坐标体系）

配 `scripts/wxclick.ps1` / `wxfarm.ps1`。窗口内坐标 = 屏幕坐标 − 窗口左上角，实测需 `+8, +11` 补偿（随 DPI 变化，首次探针验证）。

用户已固定窗口位置；窗口一旦移动，本表作废，重校（SKILL.md 第 2 节）。

## 副本流程 · 冥渊模式

```
选角 → 开始游戏(692,450) → 地图(57,79) → 冥渊(183,265)
→ 开启冥渊(725,470) → 选目标图 → 开始战斗 → 立即开自动(155,130)
→ 「再来一次」(640,212) 循环
```

- 「开启冥渊/冥渊模式」同一按钮来回切换，状态用按钮文字确认。
- 「选择奖励」面板只点「免费」图块（约 (170,200)），绝不点「支付金币 4500」。

## 副本流程 · 堕落圣殿

```
冒险(649,470) → 副本(582,420) → 远古副本(55,183) → 堕落圣殿(283,275)
→ 开始战斗(651,428) → 等3.8s → 自动战斗(155,130)
→ 「再来一次」(640,212) 循环
```

- 一场 35~60s，每场 7 体力；自动战斗跨场保留，不要重复点。
- 结算两金按钮右侧竖排：再来一次在上、返回城镇在下，中心距约 57px。
