# 坐标与标定档案（设计坐标体系，基准 1138×708；仅支持当前这台电脑）

> **本文件只存标定数据**：坐标表、缩放换算、像素判定、探针校准、按钮判定源。
> 操作流程已拆至 `features/dungeon-runs.md`（副本）与 `features/daily-claim.md`（每日领体力）；
> 机制数值在 `game-mechanics.md`；事件根因在 `incidents.md`。

配 `scripts/wxclick.ps1` / `wxgrind.ps1` / `wxprobe.ps1`。
基准：2560×1440 @125%；**设计坐标 = 1138×708（2026-10-25 15:4x 用户定版）**。本文件所有坐标均为设计坐标；文档数字可直接照抄，脚本运行时自动换算。历史窗口尺寸 1146×711 / 1142×703 仅作复盘记录，不再是标定基准。
**用户定论：游戏 UI 严格等比缩放（2026-10-25 肉眼初判，10-26 wxcanvas 实测坐实）；跨机器不支持（单机定版）。**
**客户区结构模型（2026-10-26 实测定版，wxcanvas.ps1 两尺寸实测）**：客户区 = `[微信内嵌标题栏 固定 55px 不缩放] + [游戏画布 等比缩放]`。几何层 `S=min(宽/1138, (高-55)/653)`，纵向 `screen_y = OY + 55 + (design_y-55)×S`；归一化抓图只取画布区（1138×653）贴回 1138×708 顶部 55 行填白。**基准 1138×708 时 S=1 与旧模型重合，全部档案坐标零失效**；支持任意窗口尺寸（含非等比/缩小窗，S 范围 0.40–2.0）。常量 `$WX_CHROME_H=55`（_wxcommon.ps1），preflight 开局自动审计，改动须经 wxcanvas 实测确认。
**`wxresize` 已降级为可选工具**：开局不再强制复位；仅窗口明显异常时手动恢复。事件19 的 8px 重排教训仍成立——**若同比例尺寸下模板持续 UNKNOWN**（真实布局重排），才走 `wxrecrop` 重裁。

游戏：勇士之心（appid `wx77d3595d9d76a623`），区服「巨龙山脉17」，appVersion 3.17.4。

## 显示图缩放陷阱（实测数据，勿再踩）

`Read` 显示截图被缩放。**WorkBuddy（2026-10-23 实测）：1146×707 PNG 显示约 456×283，系数 ≈0.40，直读偏差 ~2.5 倍**；正确方法=比例归一化（量值÷显示尺寸×PNG 实际尺寸），实测「进入游戏」换算 (573,527) vs 档案 (571,527)，误差 ≤2px。Trae 旧数据：系数 0.894，偏差实测 +92,+59。

## 自动战斗按钮（判定源，设计坐标 1138×708；2026-10-25 21:2x wxrecrop 重裁）

- **布局（vs 1146×711 历史布局）**：按钮为圆形图标**在文字上方**堆叠；图标区 (210,144)-(238,172)，文字区 **(195,175)-(253,187)**（wxrecrop 自动 bbox 实测，59×13）。点击点 (224,181)。
- 关=「自动战斗」▶图标；开=「取消自动」⏸图标。**文字内容是唯一可靠判据**——按钮底色受地图背景染色、中央白字 tip 受特效干扰，均不可靠；血量与自动战斗零关系。tip 判定代码已彻底删除（铁律第2条）。
- 模板：`assets\btn_auto_off.png` / `btn_auto_on.png`（wxrecrop 自动裁剪，59×13，交叉距离 0.762；历史备份 .bak-1138x703/.bak-1146x711/.bak-1142x703）。**客户区尺寸变化由运行时等比换算吸收，无需复位或重裁**；仅当同比例尺寸下模板持续 UNKNOWN（真实布局重排）→ wxrecrop 一条龙重裁，禁止手工流程。
- ⚠️ **结算画面（含战败提示面板）下按钮 HUD 可见但不可点**（2026-10-25 实测：两次 gated 点击无效果）；且 settle 屏点击可能延迟生效到下一场——gated 判定必须以模板为准，严禁凭点击次数推断状态。
- 切角色后按钮必回「自动战斗」(关)——自动战斗与冥渊模式均在切角色后重置。
